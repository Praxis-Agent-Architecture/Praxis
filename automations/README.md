# Praxis Automations

This directory is for repository maintenance automation only.

- `clean-dist.mjs`: remove generated package build output.
- `copy-dist-assets.mjs`: copy non-TypeScript assets into generated build output.

Interactive example frontends, live chats, tool labs, and matrix runners belong in
`examples/scripts/`, not here.

`automations/` is not part of the public runtime API and is not included in the npm
package.
